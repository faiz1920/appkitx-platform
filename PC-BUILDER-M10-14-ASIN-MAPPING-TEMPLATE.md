# Manual ASIN Mapping Review Template (M10.14)

Status: **blank pilot template, uncommitted for review**. This document does not
contain real ASINs, Amazon product evidence, catalogue changes or approved
mappings. Amazon-specific fields must remain blank until a named reviewer
records evidence from an actual Amazon.in product page.

- Parent report: `PC-BUILDER-M10-14-AMAZON-READINESS-GATE.md`
- Contract: M10.12 `ProviderProduct` / `ProviderProductMapping`
- Marketplace: Amazon.in (`www.amazon.in`)
- Market/region: `in` / `IN`
- Currency: INR
- Condition: New only for PC Builder pricing
- No synthetic examples are included to avoid fabricating Amazon product
  evidence.

## 1. How to use this template

1. Select a catalogue component with source-verified identity evidence.
2. Manually locate the exact Amazon.in listing using the manufacturer MPN/GTIN
   and model. Do not use search-result snippets as evidence.
3. Record the ASIN, product URL, title, brand/manufacturer, model, item part
   number, seller, condition and variant context.
4. Re-open the manufacturer evidence and compare exact identity.
5. Apply the decision rules in section 4.
6. Record reviewer, date, evidence URLs, notes and status.
7. Let the system compute the evidence fingerprint; never invent one.
8. Run duplicate/conflict audit before approval.
9. Only a named human approver may set `review_status: approved` and
   `mapping_status: verified`.
10. Revalidate on identity/content/variant/seller/lifecycle change or at the
    pilot review interval.

## 5. Decision rules

| Situation                                             | Required decision                                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Exact manufacturer + exact authoritative MPN          | `candidate`; human approval required before `verified`                                     |
| Exact GTIN + manufacturer agreement                   | `candidate`; human approval required before `verified`                                     |
| Exact MPN/GTIN but manufacturer disagreement          | `rejected`; never verify                                                                   |
| Model + manufacturer only                             | `needs-review`; human investigation required                                               |
| Title-only similarity                                 | `unverified`/`rejected`; title never establishes identity                                  |
| Amazon `itemPartNumber` only                          | `needs-review`; never treat as authoritative MPN without independent manufacturer evidence |
| Regional SKU or revision ambiguity                    | `rejected` or `needs-review`; do not guess                                                 |
| Bundle, multipack, accessory or multi-component kit   | `rejected`; must not map to a different single component                                   |
| Parent ASIN with multiple child products              | Map child ASIN only after review; parent ASIN alone insufficient                           |
| Used/refurbished/unknown condition                    | `rejected` for PC Builder pricing; pilot is New-only                                       |
| Discontinued/superseded listing                       | Record lifecycle; do not create a new verified mapping without review                      |
| Multiple ASIN candidates                              | `needs-review`; never select the first                                                     |
| Same ASIN mapped to different components              | Fail closed; registry conflict                                                             |
| Same component with multiple legitimate ASINs         | Allowed only with distinct variant/region context and separate review                      |
| ASIN content/title/manufacturer/model/variant changes | Review invalidated; revalidate                                                             |
| Seller context changes                                | Revalidate if material to the listing identity                                             |
| Price/stock changes                                   | Not identity evidence; do not change mapping                                               |

## 6. Review status and approval rules

| Mapping status | Allowed review status                  | Meaning                                   |
| -------------- | -------------------------------------- | ----------------------------------------- |
| `candidate`    | `not-reviewed`                         | Automatic exact evidence; not approved    |
| `needs-review` | `not-reviewed` or `needs-revalidation` | Probable/ambiguous/missing evidence       |
| `rejected`     | `not-reviewed` or `rejected`           | Conflict or human rejection; never usable |
| `verified`     | `approved`                             | Named human approval of current evidence  |

Additional rules:

- `approved` requires a named reviewer, review date, notes, provider product
  URL, previous status and current evidence fingerprint.
- The reviewer cannot be `opencode-…`, `system`, `automated` or `fixture`.
- A review fingerprint that no longer matches the evidence invalidates the
  approval; the mapping becomes `needs-review`.
- No automatic process may create a human-approved mapping.
- A candidate is not a verified mapping.
- Rejected mappings are never returned as usable mappings.

## 7. Evidence checklist

Before setting `needs-review` or `candidate`, confirm:

- [ ] Catalogue component exists and has source-verified MPN and/or GTIN.
- [ ] Manufacturer evidence URL is an authoritative manufacturer source.
- [ ] Manufacturer evidence was re-opened on the recorded date.
- [ ] Amazon.in product page was re-opened on the recorded date.
- [ ] ASIN is 10 alphanumeric characters and belongs to the exact listing.
- [ ] Amazon title is recorded but not used as sole identity evidence.
- [ ] Amazon brand/manufacturer is recorded separately.
- [ ] Amazon model and item part number are recorded separately.
- [ ] MPN/GTIN comparison is exact and normalized.
- [ ] Condition is New.
- [ ] Seller context is recorded.
- [ ] Variant/revision/parent-child context is recorded.
- [ ] Bundle/multipack/accessory risk is checked.
- [ ] Regional SKU/revision risk is checked.
- [ ] No ASIN or evidence was fabricated.
- [ ] Duplicate/conflict audit has been run.
- [ ] Reviewer is a named human.

## 8. Revalidation triggers

Revalidate a mapping when any of the following occurs:

- ASIN changes or the listing is replaced;
- Amazon title, brand, manufacturer, model or item part number changes;
- seller/merchant changes materially;
- variant, parent/child relationship or pack size changes;
- product lifecycle changes (discontinued/superseded);
- catalogue component identity changes;
- manufacturer evidence changes;
- review fingerprint no longer matches;
- proposed pilot interval elapses (90 days or earlier if policy requires).

Price and stock changes are not identity evidence and must not change a mapping
by themselves.

## 9. Duplicate and conflict checks

- Duplicate mapping IDs: fail.
- Same ASIN mapped to different catalogue components: fail closed.
- Duplicate mapping for the same ASIN/component: fail.
- Same component/provider/region with conflicting non-null variants: fail.
- Same component with multiple ASINs: allow only when each ASIN has distinct
  variant/region context and a separate review.
- Superseded ASINs: record the replacement; do not silently overwrite history.
- Bundle ASINs: reject unless the bundle is itself a modelled catalogue
  component (not currently the case).
